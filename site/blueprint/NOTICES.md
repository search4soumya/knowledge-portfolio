# Third-party icon notices

The application code in this repository is yours to use. The icon artwork under `icons/` comes from the sources below and keeps its original terms. Official cloud icons are brand assets, not open-source code: they are included so you can build architecture diagrams, which every provider permits.

The designer only scales cloud icons uniformly. It never crops, rotates, flips, or recolors them, which keeps diagrams within each provider's guidelines.

Source: <https://aws.amazon.com/architecture/icons/> (Icon package 07312026)

AWS allows customers and partners to use these toolkits and assets to create architecture diagrams, and to include the icons in materials such as whitepapers, presentations, data sheets, and posters.
